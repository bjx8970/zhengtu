# 政途人生

一款以公务员职业生涯与公共治理为主题的模拟游戏。

**当前版本：`0.4.0-alpha.1`**（Phase 4 动态干部生态 alpha）

当前是**本地单机优先的可玩原型**。Phase 4 已在 Phase 3 基层纵向切片之上贯通有限 NPC 干部、动态岗位空缺、相对竞争和周期性组织调整：玩家从新录用科员开始，在试用期承接个人任务，经年度考核独立晋升公务员职级，正常获得乡科级副职机会并完成选拔；任职副职后切换到部门治理，处理招商、防汛和产业园政策/事件链，同时与会自行退休、调任、晋升和自主补员的 NPC 共享组织世界。

已完成严格存档解码、统一时间轴、运行时快照、职业领域内核和 Phase 4 producer/consumer 可达性门禁。Playwright 会从真实 UI 自然运行基层路径，并验证 NPC/岗位世界在玩家少操作时持续演进。云存档仍属后续阶段。

## 当前可玩内容

| 能力     | 当前状态                                                                    |
| -------- | --------------------------------------------------------------------------- |
| 建档     | 六步角色创建（基本信息→出生地→高考→学校→背景→职业线）                       |
| 职业发展 | 试用转正 → 一级科员/四级主任科员 → 副镇长 → 镇长；职务与职级双通道独立 |
| 核心循环 | 科员个人任务 / 领导部门治理 → 时间推进 → KPI/考核 → 职级或岗位机会       |
| 行动槽位 | 主要 3 个、次要 2 个、备用 1 个；按重大/次要/日常分类并执行冷却规则         |
| 时间推进 | 1 天 / 7 天 / 30 天；统一时间轴确保行动完成→月度结算→年度考核顺序           |
| 考核     | 五维年度考核（德、能、勤、绩、廉）                                          |
| 选拔     | 最小领导岗位选拔：资格复查→民主推荐→组织考察→集体决策→公示→任职              |
| 政策     | 政策提出→批准→实施→里程碑；招商与产业政策链可玩                            |
| 事件     | 阻塞式紧急事件弹窗、非阻塞收件箱、事件历史；防汛与举报调查链可玩           |
| 存档     | Schema 14 + 内容版本 `2026.08.8`；Schema 2–14 链式迁移与安全备份            |

### 实际可达页面

| 路由           | 页面           | 状态 |
| -------------- | -------------- | ---- |
| `/`            | 启动页         | 可用（含存档状态提示） |
| `/character`   | 六步建档       | 可用 |

| `/assessment`  | 考核详情       | 可用 |
| `/career`      | 晋升任命       | 可用（职级晋升 + 岗位机会任职） |
| `/policies`    | 政策列表       | 可用 |
| `/events`      | 事件收件箱     | 可用（含阻塞弹窗与事件历史） |

## 快速开始

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

无需配置后端即可使用本地自动存档。

## 质量检查

```bash
pnpm run ci        # 一键全检：format + lint + typecheck + test + validate:config + build
```

## 技术栈

SolidJS + TypeScript + Vite | Vitest | localStorage | GitHub Pages

## 工程基础

- 严格存档 Schema（Zod `.strict()` 全层级 + 跨字段一致性校验）
- 统一时间轴引擎（`advanceTimeline()`，修复跨年和结算顺序）
- 行动实例级运行时快照（理念偏离倍率绑定到具体行动）
- Store Reducer 分域拆分（action / time / career / character）
- 条件持久化（仅实际状态变化时写档）
- Playwright 端到端验收（建档、职业循环、阻塞事件恢复与持久化）
- CI 质量门禁（format + lint + typecheck + test + config + build + e2e）
