# ADR-008：职业履历资格分析

状态：已接受
日期：2026-07-30
关联：#97、#90、#98

职业资格的唯一事实来源是 `career.experiences`。`career.appointment` 仅用于验证唯一开放履历与当前任职一致，不能作为第二份可计数经历，否则当前任职会被重复统计。

分析结果不持久化 `hasMultiRegionExperience`、地区列表或摘要。资格会随当前绝对游戏日从开放履历实时派生，因此不需要时间轴节点、世界事实或存档缓存。

任职区间统一使用 `[startedAtDay, endedAtDay)`：调任日属于新任职，首尾相接不重叠。最小时长按单个任职实例判定，短期记录不自动累加，保证资格规则可审计且不被短期调动拼接绕过。

正式任职、挂职、临时和代理的地区、机构、领域、层级资格分别由 JSON 配置定义。地区与机构独立统计：同一地区的不同机构可形成多段机构经历，但只算一个地区。开放履历以当前游戏日为结束点。

统一条件解释器调用纯履历分析器；岗位机会生成、接受及最终任职前复查因此使用相同语义。履历完整性错误会产生诊断并使资格条件失败，不静默修复或忽略损坏数据。

本版本维持 Schema 8，因为没有新增持久化字段。后续如需多段累计、权重或职位经历，必须新增显式配置和 ADR，而非改变当前派生语义。
