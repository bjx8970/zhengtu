# ADR-007：岗位机会与原子任职事务

状态：已接受

岗位机会由领域信号产生，而不是由 UI 直接指定结果。机会冻结目标快照，但结算时仍按稳定 ID 复查配置、资格、限制、空缺和行动槽位；接受不等于任职成功。

`training` 与任职机会使用判别联合，因其不需要职位目标且绝不产生 `appointment.changed`。领导岗位以最小固定阶段选拔；任职成功才关闭旧履历、创建新任职与开放履历，并重建部门运行时和预算。

任职和履历采用 `[startedAtDay, endedAtDay)`，因此调任日属于新任职。事务不修改公务员职级；执行中行动或任一校验失败时整个副本被丢弃。Schema 7 到 8 会确定性补建唯一开放履历，并拒绝歧义机会、流程或履历。完整 NPC 候选池留待后续阶段。
