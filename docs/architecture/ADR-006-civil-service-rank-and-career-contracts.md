# ADR-006：公务员职级与职业契约

状态：Accepted  
日期：2026-07-29  
关联：#95、#90

公务员职级、具体职位、领导职务、机构层级和岗位领域是独立事实。职级只能按照配置中的相邻规则变更，绝不借由任职变化隐式变更。

职级规则使用 `world.metrics` 中独立的 `rank_quota.*` 职数；职位 `vacancyCount` 仅代表内容配置的基础岗位容量，不能用于职级晋升。晋升记录追加到持久化历史，冻结和处分也是持久化实体，并采用 `[startedAtDay, endsAtDay)` 有效区间。

当前任职持有稳定 `appointmentId`，而履历仍使用自身 `experience.id`。岗位机会冻结来源和目标职位快照，职业流程使用封闭的类型、状态与阶段词汇；本 PR 只固定契约，不创建机会、不运行选拔也不改变任职。

旧 L+1 目标职位晋升引擎被删除。Schema 6→7 为旧当前任职生成确定性 ID；空机会/空流程可迁移，非空旧契约因无法安全补齐快照或状态机而拒绝并备份。
